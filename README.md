# OmniMusic — prototipo Android
Reproductor MP3 local con tema oscuro y acentos verde Omnitrix, inspirado en estética futurista sin usar recursos oficiales.

## Implementado
- Permiso de audio Android 13+ y compatibilidad anterior.
- Detección automática de MP3 por MediaStore.
- Listado de título/artista, reproducción, pausa y salto de pistas.
- Diseño oscuro con acentos verdes.

## Pendiente
- Reproducción fiable en segundo plano mediante MediaSessionService y notificación.
- Carátulas, álbumes, búsqueda y listas de reproducción.
- Pruebas en dispositivo real y compilación APK.

## Compilar
Abrir carpeta en Android Studio con SDK 35 instalado y ejecutar Build > Build APK(s).
Este proyecto NO ha sido compilado ni probado en Android; es un prototipo de código fuente.
